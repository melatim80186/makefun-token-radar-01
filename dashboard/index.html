How the value is built

Every implied value follows from the snapshot's own figures — TVL, the seven-day change, how long the protocol has run with no token, and how many chains it runs on. Nothing on the board comes from a hardcoded list of names: the list below is a filter for which protocols are pre-token subjects, never an input to a value.

The multiple

Each category's multiple is the median FDV/TVL ratio of its tokenized peers (protocols in the same category with a recorded market cap; each peer ratio capped at 2.0×), shrunk toward the market median with a prior of 6 — the market median counts as six pseudo-observations, so one peer can no longer produce a confident multiple. A category with no peers takes the market median itself. The multiple is capped at 1.0× and floored at 0.02×.

implied = TVL × multiple × growth × maturity × chain
growth = 1 + clamp(change_7d, −50%, +100%) × 0.5 (unreported change counts as 0)
maturity = 0.6 + min(age_days, 1095) / 1095 × 0.4 (unknown age counts as 365 days)
chain = 1 + 0.02 × min(chains − 1, 5)

What is on the board

The snapshot's watchlist (40 protocols, read as given) plus the pre-token protocols below the $50M floor that pass every filter: they record no token (no market cap, no Gecko id, no symbol), are not a CEX, carry no version marker and no word wrapped/staked/staking, do not begin with an exchange's name, are not a product of a tokenized parent (brand guard), and are not in a category that is itself a product of a token that trades (Bridge, Canonical Bridge, Liquid Staking, Liquid Restaking, Restaked BTC, CEX).

What the data cannot say

Only 128 of the snapshot's tokenized protocols carry a recorded market cap, so only those 128 can be peers; 288 more record a token but no market cap, so no ratio can be formed for them. The snapshot carries no parentProtocol field, so a below-floor protocol that is quietly a product of a tokenized project can still slip past the brand guard when its category gives it away — the brand guard and the category exclusion catch the ones the snapshot's own signals can name, and the rest is a stated residual gap, not a claim. A protocol is always described as recording no token, never as having none.

Implied values are this entry's own claim, never one make.fun makes. They do not predict whether or when a token is issued.
